# **App Name**: Fila Fácil

## Core Features:

- Settings Configuration: Configuration screen: Configure buttons with names, prefixes, call priority, frequency, size, colors (button and text), YouTube videos order, and priority activation/deactivation switch.
- Password Request: Password Request Screen: Responsive grid with configured buttons. Click a button to generate a printable page with prefix + sequential number + date/time. Each button has a unique sequential number, incremented with each click.
- Password Call: Password Call Screen: If priority switch is active, display a “Call Password” button with priority selection and a “Repeat Password” button. If inactive, display independent buttons for each configured password type.
- Display Screen: Display Screen: Split into left (30% - last called passwords list) and right (70% - top: YouTube videos rotation, bottom: last called password display).

## Style Guidelines:

- Primary color: Use a calming blue (#5DADE2) to promote trust and efficiency in the queueing system.
- Background color: Light gray (#ECF0F1) to provide a clean and neutral backdrop, ensuring readability and minimizing distractions.
- Accent color: Use a warm orange (#F39C12) for interactive elements and call-to-action buttons to attract attention and guide users.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text, providing a balance of modern aesthetics and readability. This ensures that information is both visually appealing and easily accessible for all users.
- Use clean, minimalist icons to represent different queue types and actions. Icons should be easily recognizable and consistent throughout the application.
- Maintain a clear, intuitive layout with sufficient spacing and contrast to ensure information is easily scannable and digestible at a glance.
- Implement subtle, non-distracting animations and transitions to enhance user engagement and provide visual feedback. Animations should be smooth and purposeful, improving the overall user experience without being overwhelming.
